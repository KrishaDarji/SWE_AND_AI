Shrinking code at scale

~1:15. The seven ways, ranked, using the ranking from the stats lecture. On code size, every reuse arm beats its no-reuse twin, and the human team is best, because it reused its core across domains. On code run time, ezr with reuse wins. But reuse doesn’t make the LLM cheaper: plain Python with reuse needs more tokens, dollars and minutes than without, and ezr with or without reuse ties. Plain Python without reuse is cheapest on all three. scikit-learn with reuse is dearest, partly because one trial ran on the bigger gpt-6.1-sol. Caveat: the three cost columns are ordered by totals with a 10 percent tie rule, not the full same test, because we only have totals for T1 to T3.
