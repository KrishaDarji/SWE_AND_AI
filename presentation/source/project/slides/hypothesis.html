01 · HYPOTHESIS

Does a factored library make each new skill cheaper?

TIMM HYPOTHESIS

Ten skills, one machine

Factor the symbolic half into small reusable parts, and an LLM or a human extends it with less new code and fewer errors at every step.

RIVAL HYPOTHESIS

Ten skills, ten problems

Factoring gives little benefit: skill i+1 costs about the same, whatever library sits underneath it.

Tested on a 10-skill ladder (remember → race), 3 datasets, 7 ways of writing the code.

Shrinking code at scale

~0:40. The claim we tested. Timm says the ten skills are one machine wearing ten hats, so a well-factored library makes each new skill cheaper. The rival says they're ten separate problems, so each step costs about the same. We built the same ten-skill ladder seven ways to find out.
