# AI Use Disclosure

This project used OpenAI Codex with the GPT-5.6 Luna Light model during the
experiment and repository preparation.

## Uses of AI assistance

- Drafting and revising treatment prompts and implementation plans.
- Generating or modifying treatment source code, tests, metrics scripts, and
  result-table/figure builders.
- Reviewing repository structure and checking requirements against the project
  specification.
- Performing semantic checks on requirements, skills, treatment organization,
  metrics, and result artifacts.
- Producing exploratory summaries and visualizations from recorded project
  measurements.

## Human responsibility

The student selected the research question, datasets, treatment structure,
experimental scope, and interpretation standards; ran and reviewed the
experiments; inspected generated code and outputs; and is responsible for the
final report, claims, citations, and submission.

## Verification and limitations

Generated code and analysis were checked with the repository test suite and
semantic validation tests where available. Report claims must be limited to
measurements stored in `results/`. Missing or incomplete treatment/domain
measurements are not treated as evidence, and the final report should identify
any remaining limitations explicitly.
