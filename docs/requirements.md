# Requirements

There are three client domains, with twenty customer asks each. Every ask is written in the client's words and tagged with the ladder skill it demonstrates.

| Domain | Client | Dataset | Asks |
|---|---|---|---|
| [Video encoding](requirements/x264.md) | Video-platform performance engineer | `moot/optimize/config/X264_AllMeasurements.csv` | 20 |
| [Software project planning](requirements/nasa93dem.md) | Engineering planning manager | `moot/optimize/process/nasa93dem.csv` | 20 |
| [Model configuration and quality](requirements/health-closedissues.md) | Machine-learning platform maintainer | `moot/optimize/hpo/Health-ClosedIssues0000.csv` | 20 |

Each file maps its twenty asks to the ten skills, two asks per skill: remember, guess, certify, flow, blame, justify, choose, fix, spot and race.
