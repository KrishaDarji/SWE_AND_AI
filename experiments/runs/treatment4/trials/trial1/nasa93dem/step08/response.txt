Reuse and implementation
The existing normalization, seed-42 grouped partition, training-only preprocessing,
200-tree forest, and effort estimation are reused through predict_effort.evaluate
and estimate. The general prediction API still accepts missing predictors.
The repair API recommend(rows, proposal) rejects unknown fields and requires all
22 categorical predictors to be present and nonmissing after normalization.
JSON loading reuses duplicate-key rejection. Novel nonmissing category strings
remain accepted under the existing encoder behavior; they require human review.

The new workflow searches only complete normalized training configurations,
collapses duplicates to their earliest CSV data row, and requires strictly lower
predicted effort. It minimizes the number of changed fields, then predicted effort,
then the one-based CSV data-row number. Comparisons have no tolerance. It returns
an explicit no_improving_candidate status, null recommendation/cost/reduction,
and an empty changes list when no improvement is available.

Assumptions and limitations
The dataset supplies neither intervention costs nor a calibrated risk measure.
Lower predicted Effort- is only an illustrative planning proxy, not failure
probability or measured risk. Cost is an equally weighted field count, not
monetary or operational cost. Physical effort units are unspecified.
Historical combinations do not establish feasibility for this proposal, and not
all project characteristics are controllable process settings. A human must
review feasibility, controllability, dependencies, actual costs, and proposal-time
availability. A lower model prediction can reflect observational associations,
confounding, estimation error, or search optimism. No causal savings, calibrated
risk reduction, guaranteed budget compliance, or global real-world cheapest
intervention is established. Missing-target eligibility follows the unchanged
existing partition; candidates with missing predictors are excluded. No package
installation, dependency changes, causal validation, or uncertainty calibration
was performed.
