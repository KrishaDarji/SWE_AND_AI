Reusable API (add source/ to sys.path):
from flow import ProposalFlow, replay
flow = ProposalFlow()
pending = flow.receive({'prec': 'n'})  # no outcome argument accepted
completed = flow.reveal(117.6)        # or None for a missing outcome
report = flow.report()
Call receive and reveal once each per arrival. receive validates predictor fields and stores the prediction before reveal accepts the outcome. Only completed arrivals appear in report. Snapshots are detached copies. replay consumes an iterable of parsed row mappings; it extracts only PREDICTORS, calls receive, and then reads the current Effort-.
