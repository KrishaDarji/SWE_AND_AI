API reuse:
Place source/ on PYTHONPATH and import blame.diagnose.
diagnose(rows) accepts a nonempty iterable of parsed project dictionaries with nominal predictor strings or None and finite nonnegative numeric Effort- or None. It returns a JSON-compatible report, never mutates the supplied rows, ignores other fields, and rejects invalid supplied predictor values even when the outcome is missing. For CSV input, use summarize.read_projects(path), which preserves the prior strict 29-column NASA93 schema and missing-token parsing.
