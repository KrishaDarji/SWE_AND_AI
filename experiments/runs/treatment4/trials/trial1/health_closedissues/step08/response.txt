Assumptions and limitations:
Change cost counts unequal normalized fields as a proxy for change size, not
measured intervention cost. Numeric magnitude does not change cost, and there
is no categorical ordering. Floats compare exactly after existing finite-number
normalization and categorical whitespace trimming. Row numbers are record
positions, not time. Repeated settings are separate observations. If identical
settings have a lower recorded MRE, cost zero explicitly identifies no setting
change. Missing secondary outcomes remain null, including unavailable deltas.
Invalid baselines raise ValueError (CLI exit 2); no improvement returns explicit
status no_improving_candidate, no recommendation and null cost/reduction.
Selection optimism and selective missingness limit interpretation. No unseen
configuration, causal inference, repeatability, statistical certification,
independent validation, invented metric formula, compute cost or deployment
guarantee is supplied. Finite recorded values are not an estimator constructor
contract. Extreme arithmetic that cannot serialize as finite JSON is rejected.
All outputs are inside Step 8. Dataset and Step 7 files were not modified.
