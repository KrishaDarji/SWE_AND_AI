Approach:
Read the CSV using the standard library and preserve its eight column names.
Trim surrounding whitespace; keep criterion as nominal strings. Parse the other
seven columns as finite numbers. Separate the five configuration fields from the
three objectives. Report nonmissing distinct values, missing counts, count, mean,
sample standard deviation, min, quartiles, median, max, and categorical counts.
Report best observed values per objective independently, without combining them.
Count repeated normalized full rows and configuration tuples separately, including
unique groups, repeated groups, records in repeated groups, and extra records.
No estimator fitting is needed for descriptive CSV summaries. scikit-learn 1.6.0
is verified and recorded; NumPy, its required dependency, is used in independent
tests rather than sharing the implementation's statistical routines.

Assumptions and limitations:
- Empty or whitespace-only cells are missing. Literal NA/null/NaN are not missing
  sentinels: numeric occurrences are rejected. Missing values are omitted from
  statistics and distinct values, with explicit missing counts. No imputation.
- Numeric values use Python floating point. Numeric spellings such as 10 and 10.0
  compare equal for distinct/duplicate checks; categorical values are case sensitive.
- Quantiles interpolate linearly at (n-1)*p. Standard deviation uses n-1 and is null
  for fewer than two observations; all-missing numeric statistics are null.
- Duplicates are normalized-value duplicates; missing cells compare equal. Repeated
  configurations ignore objectives. Extra-record counts count repetitions after
  the first record, while participating-record counts include all group members.
- The schema is fixed and empty datasets are rejected. Values are described, not
  checked against any inferred estimator restrictions or assumed physical ranges.
- Best observed objective values need not identify one common best configuration.
  No metric formulas, physical units, timelines, closure events, training validity,
  generalization claims, or compute costs are inferred from this file.
- The implementation keeps the dataset and distinct values in memory; it is a
  reusable foundation for this Health dataset/trial, not a streaming summarizer.
- Required source and reports are complete; no repository files outside the
  specified output directory were modified and no dependencies were changed.
