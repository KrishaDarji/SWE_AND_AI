All nine source modules and all nine test modules from the allowed Step 9 source/tests were copied without modification. Information boundary and audit
Both searches receive the same settings-only candidate pool. Objectives are exposed only through counted calls; all initialization evaluations count. Candidate identity is original data-row number. Each method/seed receives a fresh oracle and independent model/RNG/incumbent state. Both methods return the first evaluated strict minimum. Every run has a complete evaluation order and best-so-far history. All methods and seeds finish before frozen_selections.json is written; only then does the separate full-target audit run. Audit results are separate from frozen runs, with per-selection SHA-256 fingerprints, and are never passed back to search. Hidden-objective poisoning, callable-only access and audit-order tests exercise this boundary.

Assumptions and limitations
- Performance- is minimized; physical units are unspecified.
- No separate quality measurement exists in this dataset. The quality constraint cannot be verified; no quality values or satisfaction claim are supplied.
- Seeds repeat searches within Trial 1; they are not independent LLM implementation trials.
- Candidate identity is the original CSV data row; duplicate settings remain separate rows.
- This offline oracle replays measured outcomes; it does not execute a video encoder.
- Observed differences and win counts do not establish statistical superiority.
- The required same comparison procedure is absent from allowed inputs; analysis is pending.
- The API objective boundary is not a hostile-code Python sandbox.
- Runtime includes CSV replay overhead and fixed method order; it is not encoder runtime.
- The dataset is assumed stable during a run; before/after hashes were verified for this recorded run.
- Randomness is deterministic in the installed Python/scikit-learn environment; timing and hashes containing timing values vary.
- Equal seeds label paired descriptive repeats on this one fixed dataset; no independence or generalization inference is made.
