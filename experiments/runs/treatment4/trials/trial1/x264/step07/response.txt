Selection strategy
Use five seeded uniform initial points (or the entire budget when smaller). Refit a scikit-learn RandomForestRegressor with 64 trees and random_state=seed on evaluated observations only. Minimize mean tree prediction minus one population standard deviation across remaining candidates; every fifth evaluation after initialization is uniform exploration. Acquisition ties use the earliest CSV data row, and observed objective ties keep the first evaluated row. No hyperparameter tuning, previous recommendations, full-data rankings, target summaries or pretrained model guides this procedure. This fixed heuristic balances exploitation and exploration; it is not a calibrated uncertainty method.

Reuse and information boundary
The implementation reuses the preserved OBJECTIVE constant, Flow validation and incremental observed statistics/best tracking. It uses scikit-learn's forest directly rather than the earlier guess.evaluate routine, whose broad training/evaluation split would violate this budget. Existing summary, diagnosis, certification and justification routines remain separate regression tools. The candidate loader exposes every row's settings, skips objective cells without numeric parsing and returns no objectives. CSV framing reads raw cells; the selector receives settings-only Candidate records and a callable evaluate(data_row). CSVOracle retrieves only the requested target, charges accepted calls before reading, rejects repeated evaluations and enforces the budget independently. Unsuccessful target parses are charged and abort selection. The audit's eager target loader is invoked only after the complete selection is serialized and saved. Audit output carries a SHA-256 of that frozen pre-audit selection.

Schema and assumptions
The actual dataset has sixteen numeric settings: no_asm, no_8x8dct, no_cabac, no_deblock, no_fast_pskip, no_mbtree, no_mixed_refs, no_weightb, rc_lookahead, rc_lookahead_20, rc_lookahead_40, rc_lookahead_60, ref, ref_1, ref_5, ref_9. Performance- is the only objective and is minimized; its physical units are unspecified. There is no separate quality measurement, so the quality constraint cannot be verified. No quality values are invented and constraint satisfaction is not claimed.

Only observed dataset configurations are considered; no new encoder combinations are synthesized. Rows are evaluation identities; repeated configurations, if present in another input, are separate candidate observations. Budgets must be positive integers at most row count; seeds must be integers in [0, 2**32). The oracle simulates measurements using fixed historical CSV outcomes, rather than performing live video encodes. No generalization, noise, causality, workload-transfer, quality or optimality guarantee is made. The dataset must remain unchanged during the run. Finite numeric settings and evaluated targets are required; extreme magnitudes can exceed supported arithmetic. Target validation for unqueried rows is intentionally deferred until audit. The boundary is an explicit trusted Python API, not isolation against malicious code introspection. A caller supplying a custom evaluator is responsible for its implementation. The existing Python 3.12.6 / scikit-learn 1.6.0 environment was used without installing packages or changing versions.
