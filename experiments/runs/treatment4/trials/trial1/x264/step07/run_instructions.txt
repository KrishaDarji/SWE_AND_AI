Reusable Python API (add this directory's source/ to sys.path):
settings, candidates = choose.load_candidates(dataset_path)
oracle = choose.CSVOracle(dataset_path, budget=20)
result = choose.select(settings, candidates, oracle, budget=20, seed=42)
# Optional, only after selection is frozen:
frozen = json.dumps(result, sort_keys=True, allow_nan=False)
audit = choose.post_selection_audit(dataset_path, frozen)

select() also accepts a custom callable evaluate(data_row) returning a finite numeric objective. Candidates contain settings and CSV data-row identities only, and every callback call counts. A custom evaluator is responsible for implementing its measurements honestly. The CSV adapter enforces its own hard call cap. No separate quality capability exists.
