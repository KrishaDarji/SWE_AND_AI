Artifacts:
- source/: complete updated implementation, including unchanged Steps 1–4.
- tests/: all unchanged prior tests plus test_blame.py.
- blame.json: full ranked evidence, method settings, all pair correlations,
  constant settings, explanations and limitations.

- test_output.txt: full unittest stdout/stderr, command, exit code and wall time.

  dataset checksum and byte-for-byte preservation checks.
- metrics.csv: measured metrics; notes include passed/total counts, separate test
  and regression-demo wall times, seeds and measurement conventions.
- prompt.txt: supplied request; response.txt: implementation report.
