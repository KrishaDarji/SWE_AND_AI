Approach: ConfigurationFlow accepts each CSV result individually, keeps running averages for MRE-, ACC+, and PRED40+, and retains the best configuration for each metric (minimum MRE-, maximum ACC+ and PRED40+). The CSV reader streams rows through the same one-at-a-time API.

Assumptions and limitations: the CSV contains the required headers and numeric target values; configuration values are preserved as strings for reporting; ties keep the first result; this is a result aggregator, not a model trainer or predictor.
