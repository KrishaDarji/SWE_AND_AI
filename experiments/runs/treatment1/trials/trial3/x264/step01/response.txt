Approach: read the CSV with csv.DictReader; classify numeric columns containing only
0 and 1 as binary encoder settings; classify other numeric columns as measures; and
report run count, enabled counts/percentages, and min/max/mean/median. The implementation
uses only the Python standard library.

Measured result: 1,152 historical runs, 16 binary settings, and one measure
(Performance-). Tests passed (3 tests), and the implementation completed successfully.

Known assumptions and limitations: every data row is expected to have the same columns;
missing or nonnumeric values prevent a column from being summarized; a numeric 0/1
measure would be classified as a setting; and the report does not infer whether a
measure is better when higher or lower.
