Method: each setting receives the same primary score, eta-squared, computed from outcome-independent groups. Criterion uses observed categorical levels. Numeric settings use up to five equal-frequency groups based only on the setting values; boundaries and information loss are reported. Lower MRE- is better, but the score is association strength, not a causal effect or a direction by itself. Missing/nonfinite pairs are omitted per setting, constants receive zero score, and ties use the requested setting order.

EZR machinery adapted: finite/type-safe parsing inspired by thing(), streaming-style numeric summaries (mean, median, spread), sorted deterministic handling, and grouped summaries/ranking ideas from the supplied NUM/SYM, sorted, keysort, and ranking-related code. No Lua is invoked and no prior implementation is used.

This is marginal association only; correlated settings can share explanatory information, and grouped numeric analysis loses within-bin detail. No adjusted model was used.
