The implementation streams records in CSV order, applies Welford-style incremental count/mean/sample-variance updates, and keeps the lowest finite `Performance-` with its record ID and defensive full configuration copy. Empty input yields no snapshots; missing/nonfinite outcomes are skipped; ties retain the first best record. Snapshots are deep-copied.

The implementation adapts EZR's iterator/CSV streaming machinery, `NUM.add` one-pass summary update, and `least` min-so-far reducer. It is independent Python using only the standard library.
