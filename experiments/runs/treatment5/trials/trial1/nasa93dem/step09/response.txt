The implementation uses log1p-transformed, robust median/MAD scores (threshold 3.5), includes the assessed record in reference statistics, preserves CSV identifiers, and emits JSON null with reasons for undefined/unbounded values. EZR-inspired elements are numeric summary handling, explicit missing-value behavior, and simple CSV/type parsing; no Lua or external packages are used.

Flags are investigation candidates. Large projects may legitimately have large effort or defect counts. This is a marginal screen: it is not scope-adjusted, does not establish detection accuracy without labels, and does not provide prediction uncertainty.
