# Complete source code

See `source/fix_recommender.py` in this directory. It loads the x264 CSV, trains a RandomForestRegressor, and ranks all Hamming-distance-one setting flips.

# Tests

See `tests/test_fix_recommender.py`.

# Run

`python3 source/fix_recommender.py`

# Approach

The slowest observed row is the default input. Each possible single binary setting flip is scored by a scikit-learn random-forest model, and the lowest predicted performance value is returned. A JSON configuration can be supplied with `--config`.

# Assumptions and limitations

Performance- is treated as a lower-is-better runtime metric; all settings are binary; the CSV has the final column as the target; model predictions are estimates and are not a substitute for running the encoder.
