Implemented an independent x264 configuration justification tool.

Approach: load the CSV, parse binary settings and Performance-, train a scikit-learn RandomForestRegressor with a deterministic holdout validation split, then fit on all rows and rank only measured configurations. The lowest predicted measured configuration is reported with its observed value, dataset statistics, percentile evidence, and validation metrics. The output also advises workload validation before rollout.

Tests: 2 tests passed.
Run command:
python3 step06/source/justify_config.py /Users/RadhaKrishna/Desktop/SWE_AND_AI/moot/optimize/config/X264_AllMeasurements.csv

Known assumptions and limitations:
- Lower Performance- is assumed to be better.
- Recommendations are restricted to configurations present in the dataset.
- The holdout score is a sanity check, not a guarantee of production performance.
- The dataset is assumed to contain integer-valued feature columns and numeric Performance- values.
