Treatment 3, Trial 2, Dataset 3 — Health-ClosedIssues

Implementation
--------------
`source/race_skill.py` validates the CSV schema and numeric metrics, one-hot encodes the categorical criterion, and trains a deterministic ExtraTrees multi-output regressor (random_state=3, n_jobs=1). It ranks the 4,000 evaluation rows by predicted utility and selects the highest-ranked row. Utility is the equal-weight mean of normalized ACC+ and PRED40+ minus normalized MRE-. Normalization bounds come only from the first 6,000 rows.

Baseline and protocol
---------------------
Rows are evaluated in file order. Rows 0–5,999 are historical training data; rows 6,000–9,999 are the holdout window. The historical baseline selects the highest observed utility in the first window. Both methods are scored with the same training-derived utility scale. The protocol is reproducible through fixed model randomness, fixed split, and single-thread execution.

Uncertainty, assumptions, and limitations
------------------------------------------
This is one ordered split, not a confidence interval or significance test. The file order is assumed to represent time/order; if it is arbitrary, the historical interpretation is invalid. The selector ranks observed holdout configurations using only their configuration fields, while the baseline is restricted to a previously observed winner. The composite utility weights the three metrics equally after min–max scaling, which is a judgment call. Results can change with another split, utility weighting, candidate set, model seed, or metric noise. The baseline's historical observed result is used as its performance estimate, so it is not a fresh retrial and may be optimistic. No causal claim is made.
