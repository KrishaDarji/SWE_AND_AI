Uncertainty and limitations
---------------------------

Outcomes are included, so the method spots unusual project records rather than only unusual planning inputs. Correlated size/effort/defect fields can amplify one underlying scale difference. The robust explanations are marginal, not causal, and use global medians rather than peer groups. The 10% contamination setting is a review-list size, not an estimated error rate.
