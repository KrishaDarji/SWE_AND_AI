Implemented Step 3 by extending the Step 2 source. The existing summarize_csv and predict_quality APIs and CLI behavior remain available. Added certify_families and --family-column to compare configuration families pairwise across selected quality metrics. MRE- is minimized; ACC+ and PRED metrics are maximized. A family is reported as reliably better only when every requested metric has a non-zero conservative normal-approximation confidence interval and the same winner.

The real dataset was certified by criterion. It contains absolute_error, poisson, and squared_error families. squared_error is reliably better than absolute_error and poisson across MRE-, ACC+, and PRED40+. No reliable all-metric winner was found between absolute_error and poisson because PRED40+ was inconclusive.

Reused: Step 2's CSV parsing, numeric handling, summary schema, prediction distance logic, quality-prefix defaults, and CLI entry point. Step 3 tests cover summary behavior, prediction behavior, certification, and the certification CLI.

Assumptions and limitations: family identity is the tuple of values in the supplied family columns; this run uses criterion. MRE-prefixed metrics are treated as errors to minimize, while all other selected metrics are maximized. Reliability uses a conservative 1.96 normal-approximation interval for independent group means, with no multiple-comparison correction; it is an empirical screening rule, not proof of causal superiority or generalization. Missing metric values make that metric inconclusive. Only Python standard-library modules are used.
