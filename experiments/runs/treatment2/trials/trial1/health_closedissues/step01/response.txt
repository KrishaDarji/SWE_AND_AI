Implemented a reusable CSV model-quality summarizer in source/model_quality_summary.py.

The architecture separates CSV loading, value parsing, column summarization, metric/configuration classification, aggregate summarization, and CLI rendering. Metrics are recognized by a trailing '+' or '-' convention; all other columns are configuration settings. The JSON result includes row/column counts, field classifications, missing counts, numeric min/max/mean/median, and categorical frequencies/mode.

Tests cover classification, numeric and categorical statistics, and an end-to-end temporary CSV. The implementation and tests use only Python’s standard library.

Known assumptions and limitations:
- A field ending in '+' or '-' is treated as a model-quality metric; other fields are configurations.
- A column is numeric only when every non-empty value parses as a finite float; mixed columns are categorical.
- The full CSV is loaded into memory, which is appropriate for this dataset but not streaming-oriented.
- Summary statistics do not include standard deviation, correlations, or optimization ranking.
