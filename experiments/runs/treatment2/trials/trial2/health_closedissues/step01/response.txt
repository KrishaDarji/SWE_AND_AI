Assumptions and limitations:
- By default, the first three CSV columns are quality metrics and remaining columns are configurations.
- Numeric values must parse as finite Python floats; nonnumeric configuration values are treated as categorical.
- The summary describes distributions and does not rank configurations, infer metric direction, or train models.
- Only the Python standard library is used.
